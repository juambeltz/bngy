#  Catálogo de Autos

Bienvenido a **Catálogo de Autos bngy**, una aplicación web creada para la gestión de autos nuevos y usados. Esta app permite explorar vehículos de diferentes categorías, consultar detalles y realizar contacto con la concesionaria.

## Tecnologías utilizadas

- **React**: Librería de JavaScript para construir interfaces de usuario interactivas.
- **Vite**: Herramienta de construcción ultrarrápida para proyectos de frontend, que optimiza el desarrollo con recarga en vivo y compilación más eficiente.
- **Tailwind CSS**: Framework de CSS que permite diseñar interfaces de usuario de manera rápida y flexible mediante clases utilitarias.
- **API REST**: Utilizada para consumir datos sobre los autos desde un archivo JSON, permitiendo que la aplicación se mantenga dinámica y actualizada.
